# Сервер «Алиф»

Делает две вещи:

- **проверка произношения** (`POST /check`): запись из приложения распознаётся бесплатно
  (Groq Whisper без банковской карты или Azure Speech, 5 часов в месяц) и сравнивается с правильным ответом;
- **ИИ-учитель** (`POST /tutor`): вопросы ученика уходят в Google Gemini (бесплатный ключ),
  ответ приходит по-русски.

Ключи хранятся только здесь, в `server/.env`. Их нельзя класть в приложение.
Пошаговая инструкция, как получить ключи, есть в главном `README.md`.

## Настройки (`server/.env`)

| Переменная | Что это |
|---|---|
| `GROQ_API_KEY` | Ключ Groq для проверки голоса, без карты (console.groq.com) |
| `GROQ_MODEL` | Модель распознавания, по умолчанию `whisper-large-v3` |
| `AZURE_KEY` | Ключ ресурса Speech. Если указан, голос проверяет Azure |
| `AZURE_REGION` | Регион ресурса, например `westeurope` |
| `GEMINI_API_KEY` | Ключ из Google AI Studio |
| `GEMINI_MODEL` | Модель, по умолчанию `gemini-3.1-flash-lite` |
| `APP_TOKEN` | Любая длинная строка. Такая же нужна в `EXPO_PUBLIC_SERVER_TOKEN` |
| `SPEECH_LANGUAGE` | Язык распознавания, по умолчанию `ar-SA` |
| `PASS_SCORE` | Насколько услышанное должно совпадать с ответом, от 0 до 100. По умолчанию 75 |
| `PORT` | Порт, по умолчанию 8787 |

Без ключей Groq и Azure проверка голоса выключена, без ключа Gemini выключен учитель. Остальное работает.

## Запуск

Нужен Node.js 22. ffmpeg ставится вместе с `npm install`.

```
npm.cmd run server
```

Сервер покажет, какие функции включены, и адрес для приложения, например
`EXPO_PUBLIC_SERVER_URL=http://192.168.1.10:8787`. Его нужно вписать в `.env` в корне проекта.
Телефон с Expo Go должен быть в той же сети Wi-Fi.

## Защита

- запросы без `APP_TOKEN` отклоняются;
- не больше 30 запросов в минуту с одного адреса;
- записи голоса не сохраняются;
- учитель получает только последние 12 сообщений и название текущего урока.

## В облаке (Render, бесплатно, без карты)

В корне проекта лежит `render.yaml`, по нему Render всё настроит сам.

1. Зайдите на render.com и войдите через GitHub.
2. Нажмите **New → Blueprint** и выберите репозиторий `alif`. Если его нет в списке, нажмите
   «Configure GitHub» и дайте Render доступ к нему.
3. Render покажет сервис `alif-server` и попросит ключи `GEMINI_API_KEY` и `GROQ_API_KEY`.
   Вставьте их и нажмите **Apply** (Deploy Blueprint).
4. Через 3–5 минут в карточке сервиса появится адрес вида `https://alif-server-xxxx.onrender.com`.
   Откройте `https://…onrender.com/health`: должно быть `{"ok":true,"voice":true,"tutor":true}`.
5. В `.env` приложения: `EXPO_PUBLIC_SERVER_URL=https://…onrender.com`, строку `EXPO_PUBLIC_SERVER_TOKEN` удалите.

Бесплатный сервер засыпает, если минут 15 нет запросов, и просыпается около минуты.
Приложение будит его при запуске, а пока сервер просыпается, показывает «Сервер просыпается…».
Когда меняется папка `server`, Render сам пересобирает сервер после `git push`.
Адрес `https` подходит и для iPhone.

## Проверка без ключей

`node server/test.mjs` проверяет сервер на подменённых ответах Azure, Groq и Gemini.
Этот тест не показывает, насколько точно распознаётся речь и насколько хорошо отвечает учитель.
