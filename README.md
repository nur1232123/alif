# Алиф

Курс арабского на год для Android и iPhone: 52 недели, 1092 урока, три урока в день. Алфавит занимает 1 неделю.
Приложение написано на Expo.

## Запуск на телефоне

```
npm install
npx expo start
```

Отсканируйте QR-код в приложении Expo Go.

## ИИ-функции: озвучка, голосовой экзамен, ИИ-учитель

Все три работают через свой небольшой сервер. Ключи лежат только в `server/.env` на вашем компьютере
и не попадают в приложение и на GitHub. Оба сервиса бесплатны в пределах лимитов.

**Ключ Groq** (проверка голоса, без банковской карты)

1. Зайдите на console.groq.com и войдите аккаунтом Google.
2. Слева откройте **API Keys**, нажмите **Create API Key**, скопируйте ключ.
3. Впишите его в `server/.env` строкой `GROQ_API_KEY=...`.

**1. Ключ Azure Speech** (озвучка; проверка голоса, если нет Groq). Azure просит банковскую карту для проверки

1. Зайдите на portal.azure.com и создайте ресурс **Speech service** (бывает в разделе Azure AI services).
2. Тариф (Pricing tier): **Free F0**. Регион: например **West Europe**.
3. Откройте ресурс, раздел **Keys and Endpoint**: скопируйте **KEY 1** и **Location/Region** (например `westeurope`).

**2. Ключ Gemini** (ИИ-учитель)

1. Зайдите на aistudio.google.com и войдите аккаунтом Google.
2. Нажмите **Get API key**, затем **Create API key**, скопируйте ключ.
3. На бесплатном тарифе Google может использовать вопросы для улучшения своих сервисов, поэтому в приложении написано не вводить личные данные.

**3. Настройка** (Windows, в папке проекта)

```
npm.cmd install
copy server\.env.example server\.env
notepad server\.env
```

Впишите `GROQ_API_KEY` (или `AZURE_KEY` и `AZURE_REGION`), `GEMINI_API_KEY` и придумайте `APP_TOKEN` (любая длинная строка), сохраните.

**4. Озвучка курса** (один раз, около 6 тысяч символов из бесплатных 500 тысяч в месяц)

```
npm.cmd run audio
```

Записи появятся в `assets/audio`, приложение будет использовать их само. Другой голос: `VOICE=ar-SA-ZariyahNeural` в `server/.env`.

**5. Сервер.** Постоянно он работает в облаке Render, как это настроить, написано в `server/README.md`. Для проверки можно запустить его и на своём компьютере (держите окно открытым)

```
npm.cmd run server
```

Сервер покажет строку `EXPO_PUBLIC_SERVER_URL=http://...`. В корне проекта сделайте `copy .env.example .env`,
откройте `.env`, вставьте этот адрес и тот же `APP_TOKEN` в `EXPO_PUBLIC_SERVER_TOKEN`.

**6. Запуск приложения** (во втором окне)

```
npx.cmd expo start -c
```

Телефон и компьютер должны быть в одной сети Wi-Fi. Если Windows спросит про брандмауэр для Node.js, разрешите доступ в частной сети.
Пока адрес сервера не указан, голосовых заданий и ИИ-учителя в приложении нет, всё остальное работает.
Точность проверки голоса подбирается числом `PASS_SCORE` в `server/.env` (по умолчанию 75).

На iPhone в беззвучном режиме голос приложения может быть не слышен.

## Подписка «Алиф Премиум»

- Бесплатно: этапы 1–2 (алфавит и чтение, 5 недель), тренировки, ИИ-учитель 3 вопроса в день.
- Премиум: этапы 3–5 и учитель без ограничений. $4.99 в месяц или $29.99 в год, первые 7 дней бесплатно.
- Настройки в коде: `src/lib/premium.tsx` (`FREE_STAGES`, `FREE_TUTOR_PER_DAY`).

Оплату ведут Google Play и App Store, подписки учитывает RevenueCat (бесплатно до $2 500 выручки в месяц).
В Expo Go настоящей оплаты нет. В режиме проверки (`EXPO_PUBLIC_TEST_MODE=1`) в Профиле есть
переключатель «Премиум включён», им можно посмотреть приложение глазами бесплатного ученика.

**Настройка перед выпуском**

1. В Google Play Console и App Store Connect создайте две подписки:
   `alif_premium_monthly` ($4.99, 1 месяц) и `alif_premium_annual` ($29.99, 1 год),
   у обеих бесплатный пробный период 7 дней.
2. На app.revenuecat.com создайте проект, подключите оба магазина, импортируйте подписки.
3. Создайте доступ (Entitlement) с идентификатором `premium` и привяжите к нему обе подписки.
4. В предложении (Offering) `default` добавьте пакеты Monthly и Annual.
5. Скопируйте публичные ключи SDK (Project settings → API keys) в `.env`:
   `EXPO_PUBLIC_RC_ANDROID_KEY=goog_...` и `EXPO_PUBLIC_RC_IOS_KEY=appl_...`.
   Это публичные ключи для приложения, секретов в них нет.
6. Политика конфиденциальности должна открываться по общедоступной ссылке:
   укажите её в `EXPO_PUBLIC_PRIVACY_URL`. Условия использования по умолчанию стандартные от Apple.
7. Проверять покупку нужно в сборке, установленной из закрытого тестирования Google Play
   или TestFlight, с тестовым аккаунтом: там деньги не списываются.

## Сборка APK

```
npx eas-cli@latest build -p android --profile preview
```

## Выпуск в App Store

Нужен аккаунт Apple Developer Program. Mac не нужен, сборка идёт в облаке Expo.

```
npx eas-cli@latest build -p ios --profile production
npx eas-cli@latest submit -p ios
```

Тексты для магазина: `STORE.md`. Политика конфиденциальности: `PRIVACY.md`.

Перед публикацией замените идентификатор `app.alifarabic.mobile` в `app.json` на свой.

## Веб-версия для просмотра

```
npm run web:build
```

Результат: один файл `web-dist/alif.html`. В нём нет голосового экзамена и ИИ-учителя.
